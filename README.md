# GameVerse

Projeto de site escolar sobre jogos, feito com HTML, CSS e JavaScript. Inclui páginas de apresentação, catálogo, favoritos e jogos, além de elementos interativos.

## Como visualizar

Abra `cards.html` em um navegador. Mantenha a pasta `imagens` junto dos arquivos HTML para carregar as imagens do projeto.
